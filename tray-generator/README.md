# Tray Generator (v8)

Parametric, stackable, lightweight trays and boxes for 3D printing, with lids, compartments, wall patterns, weight/cost/print-time estimates and STL/3MF export.

**Live site:** https://rahul576.github.io/3d-designing-tools/tray-generator/

The app is a single offline HTML file. `index.html` is always the latest version; every version is kept under `versions/vN/index.html` (v2 to v8). Nothing is uploaded; it runs entirely in the browser. New in v8: an "Inner walls too" checkbox under Wall pattern cuts the pattern through the partitions between compartments as well as the outer walls (see [inner-walls-pattern.png](inner-walls-pattern.png)). See [README.txt](README.txt) for the full feature guide and folder layout.
